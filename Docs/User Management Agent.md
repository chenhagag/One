# User Management Agent — One

## מטרה
סוכן שמנהל את מחזור החיים של משתמשים באופן אוטומטי — מרגע ההרשמה ועד הכניסה למאגר ההתאמות. הסוכן רץ דרך Claude Code, קורא את מצב המשתמשים מה-API, מבצע פעולות, ומייצר דו"חות.

---

## שלב 1: ריצה על משתמשים (Pipeline Run)

### מה הסוכן עושה בכל ריצה:

#### משתמשים חדשים (new)
1. שולח מייל ברוכים הבאים (או הודעת מערכת למי שלא מקבל מיילים)
2. מסמן כ-`admin_contacted`
3. מדווח: "נשלחו X מיילים / Y הודעות למשתמשים חדשים"

#### זוגות לטיפול (couples)
1. שולח מייל/הודעת זוגות (אם עדיין לא נשלח)
2. מסמן כטופל
3. מדווח: "טופלו X זוגות"

#### השלימו את כל התהליך (completed_all)
תנאי: צ'אט כללי סגור + קוגניטיבי סגור + טעם סגור

**בדיקת עדכניות:**
- אם יש 7+ הודעות חדשות מאז הניתוח/תובנות האחרונים → הרץ ניתוח מחדש + כתוב תובנות מחדש

**טיפול:**
1. הרץ ניתוח (`POST /admin/users/:id/reanalyze`) — אם נדרש
2. כתוב תובנות בעצמך (קרא את כל השיחות, אל תשתמש ב-generate-insights API) — אם נדרש
3. שלח מייל כניסה למאגר / הודעת מערכת
4. סמן צ'קליסט: analysis_run ✓, insights_entered ✓, email_sent ✓
5. סמן "סיימתי טיפול" (`mark_done`)

#### כמעט השלימו (completed_partial)
תנאי: צ'אט כללי סגור, אבל חסר קוגניטיבי ו/או טעם

**טיפול:**
1. הרץ ניתוח + כתוב תובנות על בסיס מה שיש
2. **לא לשלוח מייל כניסה למאגר** — הם עדיין לא סיימו
3. אחרי כמה ימים — שלח תזכורת להשלים את הערוצים החסרים
4. כשישלימו → יעברו אוטומטית ל-completed_all

#### מקרה מיוחד: בתהליך עם ערוצים שהושלמו
- משתמשים ב"בתהליך" שסיימו קוגניטיבי ו/או טעם אבל לא צ'אט כללי
- הסוכן מזהה ומדווח: "X משתמשים בתהליך עם ערוצים שהושלמו — שווה לעקוב"

#### מוכנים למאגר (ready_pool)
- **עם תמונות**: מדווח "ממתינים לניתוח חיצוני ידני" (או מריץ אוטומטית בשלב מתקדם)
- **בלי תמונות**: מדווח "ממתינים לתמונות"
- אחרי ניתוח חיצוני → מכניס למאגר (`enter_pool`)

#### במאגר (pool) + לא דורשים טיפול
- סורק פעילות חדשה ומדווח אם יש

### מה הסוכן לא עושה (דורש אישור ידני):
- כניסה למאגר של משתמשים בלי תמונות
- ניתוח חיצוני (ידני כרגע, אוטומטי בשלב מתקדם)
- מחיקת משתמשים

### איך מפעילים:
```
"תרוץ על המשתמשים"
"תעשה pipeline run"
```

### פלט:
דו"ח טקסטואלי בשיחה + שמירה ל-`reports/pipeline-run-YYYY-MM-DD.md`

## שלב 2: משימות יומיות (Daily Tasks)

### 2.1 הורדת שיחות
- קורא את כל השיחות מ-`/admin/users/:id/full` + `conversation_messages`
- שומר ל-`conversations/user-{id}-{name}.txt` — שיחה מלאה לכל משתמש
- מעדכן רק שיחות שהשתנו מאז הריצה האחרונה

### 2.2 סריקת תקלות בשיחות
- עובר על כל שיחה חדשה/שהשתנתה
- מחפש:
  - הפניות לאפליקציות אחרות (Tinder, Bumble וכו')
  - אמירות שהפרופילים "לא אמיתיים" או "בדויים"
  - אמירות "אני רק צ'אטבוט" או דומות
  - שאלות שחוזרות על עצמן (שאלה זהה פעמיים+)
  - תקיעות: AI לא מתקדם בנושאים
  - הודעות שגיאה או תשובות ריקות
- שומר ל-`reports/chat-issues-YYYY-MM-DD.md`

### 2.3 משתמשים לא פעילים
- מזהה משתמשים שלא נכנסו מעל 7 ימים ועדיין לא השלימו
- מפריד: חדשים לגמרי (לא התחילו) vs. באמצע תהליך
- שומר ל-`reports/inactive-users-YYYY-MM-DD.md`

### 2.4 סריקת דיווחים
- קורא דיווחי באגים/רעיונות מ-`bug_reports`
- מסכם דיווחים חדשים שלא טופלו
- שומר ל-`reports/user-reports-YYYY-MM-DD.md`

### איך מפעילים:
```
"תעשה משימות יומיות"
"daily tasks"
```

## שלב 3: הרצה מתוזמנת (Scheduled)

באמצעות Claude Code `/schedule` — הסוכן רץ אוטומטית כל יום:

```
/schedule "daily 08:00" "תרוץ על המשתמשים ותעשה משימות יומיות. שמור דו"ח ל-reports/"
```

הדו"ח היומי יכלול:
- סיכום פעולות שבוצעו (מיילים, ניתוחים, תובנות)
- תקלות שנמצאו בשיחות
- משתמשים לא פעילים
- דיווחים חדשים
- משתמשים שממתינים לפעולה ידנית

## שלב 4: יכולות מתקדמות (עתידי)

### 4.1 ניתוח חיצוני אוטומטי
- הסוכן מוריד את תמונות המשתמש
- שולח ל-GPT-4o Vision לניתוח מראה חיצוני
- ממלא את ה-look traits אוטומטית
- מסמן "ניתוח חיצוני" בצ'קליסט

### 4.2 תובנות מתקדמות
- כתיבת תובנות מורחבות יותר (לא רק דרך הפרומפט הקיים)
- שילוב של ציוני traits בתובנות
- התאמה אישית של הטון לפי סוג המשתמש

### 4.3 תוכן מוכוון למשתמשים
- כתיבת מאמרים מותאמים (למשל: "הטיפוס שלך — Enneagram 4 בזוגיות")
- שילוב תכונות ספציפיות של המשתמש במאמר
- שליחת תוכן למשתמשים לא פעילים כדי לעודד חזרה

### 4.4 ניטור איכות שוטף
- ציון איכות לכל שיחה (1-10)
- זיהוי דפוסים בעייתיים חוצי-שיחות
- המלצות לשיפור פרומפטים

## API Endpoints בשימוש

| Endpoint | שימוש |
|----------|-------|
| `GET /admin/user-management` | שליפת כל המשתמשים + סטטוס |
| `POST /admin/users/:id/send-email` | שליחת מייל |
| `PATCH /admin/users/:id` | עדכון שדות (admin_message, admin_notes) |
| `POST /admin/users/:id/pipeline-action` | פעולות pipeline (mark_contacted, mark_done, enter_pool) |
| `POST /admin/users/:id/update-checklist` | עדכון צ'קליסט |
| `POST /admin/users/:id/reanalyze` | הרצת ניתוח |
| `POST /admin/users/:id/generate-insights` | הפקת תובנות AI |
| `GET /admin/users/:id/full` | פרטי משתמש מלאים + traits |
| `GET /users/:id/photos` | תמונות משתמש |
| `GET /admin/reports` | דיווחי באגים |

## כללי בטיחות

1. **לעולם לא למחוק משתמשים** — רק לדווח
2. **לא לשנות ציוני traits ידניים** — רק לקרוא
3. **לא לשלוח מייל למשתמש שכבר קיבל** — לבדוק email_log קודם
4. **לא להכניס למאגר בלי תמונה + ניתוח חיצוני** — לדווח ולהמתין
5. **לשמור לוג של כל פעולה** — בדו"ח הריצה
6. **בספק — לדווח ולא לפעול**
