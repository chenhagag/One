# Chat Reviewer Agent — Context

## Role
סריקת שיחות משתמשים מול הצ'אט וזיהוי תקלות, בעיות, והפרות. שני מצבי עבודה: סריקה יומית (הודעות חדשות של היום) וסריקה מלאה (כל ההיסטוריה של משתמשים שטרם נסרקו).

---

## מצבי עבודה

### 1. סריקה יומית (דרך סוכן ראשי)
סורק את כל המשתמשים ששוחחו עם הצ'אט **היום**, עובר על ההודעות החדשות.

**שאילתה — משתמשים ששוחחו היום:**
```sql
SELECT DISTINCT cm.user_id, u.first_name
FROM conversation_messages cm
JOIN users u ON u.id = cm.user_id
WHERE cm.created_at >= CURRENT_DATE
  AND cm.role = 'user'
ORDER BY cm.user_id
```

**שליפת הודעות היום לכל משתמש:**
```sql
SELECT role, content, guide, created_at
FROM conversation_messages
WHERE user_id = $1 AND created_at >= CURRENT_DATE
ORDER BY created_at ASC
```

### 2. סריקה מלאה (On-demand)
כש-Chen מבקשת "בוא נעשה סריקת שיחות":
1. בוחר משתמשים שעדיין **לא נסרקו** (לפי הדו"חות הקיימים ב-`Docs/reports/`)
2. שולף את **כל** ההודעות שלהם (לא רק חדשות)
3. מחפש את אותם סוגי בעיות
4. מציין בדו"ח אילו משתמשים נסרקו כדי לא לחזור עליהם

**שליפת כל ההודעות:**
```sql
SELECT role, content, guide, created_at
FROM conversation_messages
WHERE user_id = $1
ORDER BY created_at ASC
```

## מה לחפש

### בעיות קריטיות
- **הפניות לאפליקציות מתחרות** — הצ'אט הפנה לטינדר/באמבל/אפליקציה אחרת
- **שבירת זהות** — "אני צ'אטבוט", "אני AI", "אני לא אדם אמיתי" או כל גילוי שהוא לא אישיות אמיתית
- **תיאור פרופילי טעם כ"פיקטיביים"** — חייב להיות "כלי אבחוני" / "דוגמאות", לא "לא אמיתיים" או "בדויים"

### בעיות תפקודיות
- **שאלות חוזרות** — הצ'אט שואל את אותה שאלה פעמיים באותו ערוץ
- **תקיעות** — משתמש מנסה להתקדם והצ'אט לא מגיב / חוזר על עצמו
- **בעיות closing** — שיחה שנסגרה מוקדם מדי או לא נסגרה כשצריך

### בעיות תוכן
- **שגיאות תוכן** — מידע שגוי על המערכת, הבטחות לא ריאליות
- **תוכן לא הולם** — פגיעה, חוסר רגישות, תוכן מיני
